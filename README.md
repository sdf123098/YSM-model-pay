## 🛠️ 安装与使用教程

### 1. 将模型安装至 Minecraft
1. 确保你的 Minecraft 客户端已安装 **Yes Steve Model (YSM)** 模组（Fabric 或 NeoForge / Forge 版本）。
2. 在仓库或[在线资源站](https://sdf123098.github.io/YSM-model-pay/)下载你喜爱的 `.ysm` 模型文件或解压后的文件夹。
3. 将下载的文件放入你的 Minecraft 客户端目录：
   ```text
   .minecraft/config/ysm/models/
   ```
   *或*
   ```text
   .minecraft/ysm/models/
   ```
4. 进入游戏后按默认快捷键（通常为 `P` 或 `Custom Model Key`）打开 YSM 模型选择菜单即可应用！
